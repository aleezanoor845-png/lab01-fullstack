# Lab 01 - Web Foundations & Version Control

This repository contains my submission for Lab 01 of Full Stack Web Development.

## Contents
- `index.html` - Semantic HTML5 page structure
- `style.css` - External CSS styling linked to index.html
- `bootstrap-demo.html` - Bootstrap 5 grid, navbar, cards, and buttons demo

## How to run
Open `index.html` or `bootstrap-demo.html` directly in any web browser (Chrome/Edge). No build steps or installation required — Bootstrap is loaded via CDN.

## Topics covered
HTML5 semantic elements, CSS3 external stylesheets, Bootstrap 5 responsive grid and components, Git version control basics.
