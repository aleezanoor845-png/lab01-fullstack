# Lab 01 - Web Foundations & Version Control

This repository contains my submission for Lab 01 of Full Stack Web Development.

## Contents
- `index.html` - Semantic HTML5 page structure
- `style.css` - External CSS styling linked to index.html
- `bootstrap-demo.html` - Bootstrap 5 grid, navbar, cards, and buttons demo — extended into a one-page personal portfolio (About Me, Skills, Contact) as part of the home task, styled with a custom beige/warm color theme

## How to run
Open `index.html` or `bootstrap-demo.html` directly in any web browser (Chrome/Edge). No build steps or installation required — Bootstrap is loaded via CDN.

## Topics covered
HTML5 semantic elements, CSS3 external stylesheets, Bootstrap 5 responsive grid and components, custom CSS theming, Git version control basics.

## Home Task
`bootstrap-demo.html` was extended into a simple personal portfolio page with an About Me section, a Skills section using Bootstrap cards, and a Contact section with a styled email button.
